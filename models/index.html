How it works

Bayes scanning

The Bayesian classifier is an ML classifier trained on patches (diffs) from projects. It learns statistical associations between code tokens/contexts and patch changes to score lines with a probability that they correspond to a defect. In practice this denotes suspicious lines in the ML heatmap and complements deterministic AST/heuristic checks. See Karma Automated source code defect identification method.
